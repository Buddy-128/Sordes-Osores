# Sordes-Osores
A little raylib + C game based on the gameplay of Moorhuhn games. 
With an only exception: you shoot AI slop.

# Building
I finally added a release and i wouldn't recommend building it yourself.
There is a Makefile for gcc and mingw (make win). If you wish to compile on Windows use WSL.

## Dependencies
Everything required to build the game is in /lib for both linux and mingw.
